## Contexte
SafeHaven est une plateforme innovante de soutien émotionnel qui vise à offrir un espace sûr et confidentiel pour les utilisateurs en quête de soutien psychologique. La plateforme combine des fonctionnalités de chat intelligent, de suivi d'humeur et de partage de contenu pour créer une expérience holistique de bien-être mental.

## Objectifs
- Créer une plateforme accessible et intuitive pour le soutien émotionnel
- Offrir un espace sécurisé pour l'expression personnelle
- Fournir des outils de suivi du bien-être mental
- Faciliter les interactions entre utilisateurs de manière sécurisée

## Portée
Le projet couvre le développement complet d'une application web moderne, incluant :
- Une interface utilisateur réactive et intuitive
- Un système de chat intelligent
- Un système de suivi d'humeur
- Un système de gestion de profil utilisateur
- Une API REST sécurisée
- Une base de données robuste
